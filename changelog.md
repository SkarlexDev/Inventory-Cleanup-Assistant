# Changelog

## 1.0.0

- Add a three-list inventory review for items to review, sell, or ignore.
- Select Poor-quality items for sale by default, with saved Sell and Ignore rules.
- Add vendor auto-selling for eligible items and a `/ica` command to toggle the window.
- Add Farm Loot tracking for instance runs, including optional farm auto-sell and reagent handling.
- Add settings for zero-value items, Farm Loot, and reagent selling.
- Save window positions and provide a Discord support link.
- Use the custom logo as the addon icon.
